# 03. 요구사항과 구현 계획

대상: 작업용 AI. 자료 파악과 중요한 업무 조건 확인을 마친 뒤 사용합니다.

```text
과제 안내, 제공 자료, 지금까지 확인한 담당자 답변을 읽고 실행 계획을 정리해줘.

요구사항마다 다음을 연결해줘.
- 요구사항과 근거
- 필수 조건인지, 선택 가능한 제안인지
- 사용할 입력 데이터
- 구현할 파일·기능
- 올바르게 작동하는지 확인할 방법

최종 결과물까지 구현 순서를 나눠줘.
먼저 입력부터 결과 표시까지 실제로 작동하는 작은 기능 하나를 정하고,
그다음 나머지 필수 기능으로 확장하는 순서로 제안해줘.
현재 환경에서 실행 가능한 방법을 우선 검토해줘.

미정 조건, 내가 정할 수 있는 기술 선택, 담당자 확인이 필요한 결정을 구분해줘.
중요한 업무 조건을 임의의 값으로 채우지 마.
각 단계의 완료 기준과 직접 확인할 화면·입력 사례를 설명해줘.
아직 구현을 시작하지 말고 계획을 먼저 보여줘.
```

계획을 본 뒤 직접 결정할 것:

- 필수 기능을 모두 포함했는가?
- 첫 단계가 실제로 실행 가능한 크기인가?
- 불필요한 기능이나 설치 때문에 시간이 늘어나지 않는가?
- 어떤 조건을 가정했는지 내가 설명할 수 있는가?

구현으로 넘어갈 때:

```text
계획의 [단계/범위]를 진행해줘.
지금 확인된 조건은 [요약]이야.
해당 범위를 구현하고 실행·검증까지 마친 뒤, 변경 파일과 실제 확인 결과를 알려줘.
다음 단계에 영향을 주는 미정 사항이 발견되면 근거와 함께 밝혀줘.
```
