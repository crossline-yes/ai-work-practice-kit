# 02. 담당자에게 물어볼 질문 고르기

작업용 AI는 자료를 분석하고 구현을 돕는 상대입니다. 업무 담당자는 업무 목적, 운영 조건, 우선순위를 확인하는 상대입니다. 대화 내용이 자동으로 공유된다고 가정하지 말고, 확인된 답변을 작업용 AI에 전달하세요.

먼저 작업용 AI에게:

```text
현재 자료와 확인된 담당자 답변을 기준으로 추가 질문을 골라줘.
자료에 이미 답이 있는 질문은 제외해줘.

질문마다 다음을 적어줘.
- 현재 이해한 내용과 근거
- 아직 불명확한 부분
- 답에 따라 달라지는 계산·기능·검증
- 담당자에게 보낼 짧은 질문

필수 기능을 결정하지 못하게 하는 질문을 먼저 골라 최대 3개만 제시해줘.
단순한 기술 선택은 작업용 AI가 검토하고, 업무 규칙을 추측해 확정하지 마.
```

담당자에게 보내는 질문의 기본형:

```text
제가 자료에서 확인한 내용은 [현재 이해와 근거]입니다.
다만 [불명확한 조건]은 확인하지 못했습니다.
[구체적인 확인 질문]인가요?
이 답에 따라 [달라지는 처리]를 정하려고 합니다.
```

상황에 맞게 골라 쓰는 짧은 질문:

- 이 결과물을 누가 어떤 상황에서 사용하며, 결과를 보고 어떤 결정을 하나요?
- 필수 조건을 모두 만족할 수 없을 때 어떤 결과와 사유를 보여줘야 하나요?
- 두 목표가 충돌하면 어떤 목표를 먼저 지켜야 하나요?
- 기준과 정확히 같은 값은 허용하나요?
- 이 말씀은 반드시 지킬 운영 규칙인가요, 검토할 의견인가요?
- 제가 이해한 처리 순서는 [요약]입니다. 다른 부분이 있나요?

답변을 받은 뒤 작업용 AI에게:

```text
담당자가 다음과 같이 답변했어.
[답변]

과제 안내와 대조해 확인된 요구사항에 반영해줘.
자료와 충돌하면 충돌을 표시하고, 답변에 없는 조건을 추가하지 마.
아직 결정되지 않은 부분과 먼저 진행할 수 있는 작업을 알려줘.
```

같은 질문을 반복하기보다 답변을 요약해 재확인하세요. 질문 개수 자체가 작업의 품질을 뜻하지는 않습니다.
