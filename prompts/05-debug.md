# 05. 오류를 재현하고 고치기

대상: 작업용 AI. 오류 문구만 보내기보다 입력과 실행 순서를 함께 전달합니다.

```text
다음 오류를 조사해줘.

내가 한 일: [실행 순서]
입력: [파일·선택·값]
기대한 결과: [예상]
실제 결과: [증상]
오류 문구: [관측한 문구]

관련 코드와 실행 기록을 읽고 같은 입력으로 재현해줘.
입력 자료 문제, 계산 문제, 화면 표시 문제, 실행 환경 문제를 근거로 구분해줘.
원인을 추측으로 확정하지 말고 확인한 사실과 가설을 나눠줘.

원인을 확인하면 필요한 범위만 수정하고,
같은 입력에서 오류가 해결됐는지와 기존 정상 기능이 유지되는지 확인해줘.
원자료나 운영 기준을 바꿔 오류를 숨기지 마.

증상 → 원인 근거 → 수정 → 재검증 결과 순서로 설명해줘.
재현하지 못했다면 그 사실과 추가로 필요한 정보를 알려줘.
```

오류 상황을 설명하기 어려울 때:

```text
어디서 잘못됐는지 모르겠어. 현재 실행 방법을 확인하고,
입력 읽기·데이터 연결·계산·결과 표시 중 어느 단계까지 정상인지 조사해줘.
내가 제공해야 할 정보를 먼저 최대 3개만 물어봐줘.
```

수정 후 직접 남길 짧은 기록:

- 어떤 입력에서 어떤 문제가 있었는가?
- 실제 원인을 보여준 파일·함수·로그는 무엇인가?
- 무엇을 고쳤으며, 같은 사례와 정상 사례를 다시 확인했는가?
