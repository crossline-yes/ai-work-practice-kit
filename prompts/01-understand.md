# 01. 자료와 과제 파악

대상: 작업용 AI. 과제와 자료가 있는 작업 폴더에서 사용합니다.

```text
현재 작업 폴더의 과제 안내와 제공 자료, 기존 프로젝트를 확인해줘.
나는 개발 초보이므로 쉬운 말로 설명해줘.

다음을 중요한 순서로 정리해줘.
1. 사용자가 겪는 문제와 만들어야 할 결과물
2. 반드시 필요한 기능, 제출 파일, 실행 조건
3. 파일별 역할과 데이터 한 행의 의미
4. 주요 열의 의미·단위, 파일끼리 연결하는 식별자
5. 이미 있는 코드의 역할과 실행 방법
6. 확인된 조건, 미정인 조건, 자료 사이의 충돌
7. 담당자에게 먼저 확인할 질문 최대 3개와 각 질문이 구현에 미치는 영향

각 판단에 근거 파일과 항목을 적어줘.
파일 이름만 보고 내용을 읽었다고 판단하지 말고, 읽지 못한 자료는 밝혀줘.
표본·참고 자료와 실제 계산에 사용할 원자료를 구분해줘.
아직 수치를 계산하거나 코드를 수정하지 말고 상황부터 파악해줘.
```

답변을 받은 뒤 직접 확인할 것:

- 무엇을 입력하면 어떤 결과가 나오는 서비스인지 한 문장으로 말할 수 있는가?
- 아직 모르는 조건 중 계산이나 기능을 바꾸는 조건이 무엇인가?
- 자료의 한 행을 개인 기록과 집계 기록 중 어느 것으로 이해했는가?

짧은 재질문:

```text
설명이 길어서 핵심을 놓쳤어. 목적, 필수 결과물, 미정 조건을 각각 3줄 이내로 다시 설명해줘.
```
