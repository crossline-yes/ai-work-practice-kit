# 06. 요구사항과 결과를 검증하기

대상: 작업용 AI. 과제에 실제로 해당하는 사례를 골라 사용합니다.

```text
현재 결과물과 확인된 요구사항을 대조해줘.

각 필수 요구사항에 대해 구현 위치와 확인 방법을 찾고,
다음 중 과제에 해당하는 사례를 검증해줘.
- 정상 입력 하나를 원자료와 직접 대조
- 기준과 같은 값, 기준 바로 아래·위의 값
- 비어 있는 입력 또는 수요가 없는 경우
- 누락·중복·잘못된 형식·없는 ID 참조
- 날짜·시간·방향·단위가 다른 경우
- 조건을 모두 만족할 수 없는 경우
- 정상 입력 다음 오류 입력 또는 선택 조건 변경
- 입력 값을 바꿨을 때 결과 재계산
- 화면과 다운로드 결과의 일치

원자료를 보존하고 테스트용 사본을 사용해줘.
사례마다 입력, 예상 결과, 실제 결과, 근거를 기록해줘.
코드만 읽은 항목, 실제 실행한 항목, 미검증 항목을 구분해줘.
실행 환경에서 확인할 수 없는 항목은 이유와 내가 확인할 순서를 적어줘.

발견한 오류는 근거를 설명하고 수정·재검증해줘.
마지막으로 이 검증만으로는 보장할 수 없는 사항을 알려줘.
```

검증을 읽고 직접 확인할 질문:

- 예상 결과를 AI의 출력과 독립적으로 계산하거나 규칙에서 도출했는가?
- 실제로 어떤 입력을 넣고 어떤 결과를 관측했는가?
- 통과한 검사로도 발견하지 못할 오류는 무엇인가?
- “오류가 없었다”와 “검사한 범위에서 오류를 발견하지 못했다”를 구분하는가?

중요한 정상 사례 하나는 직접 화면에서 따라 해보고, 본인이 확인한 사실을 따로 적어두세요.
