# 08. 제출 전 확인과 인수인계

대상: 작업용 AI. 새 기능을 계속 추가하기 전에 필수 결과물을 확인합니다.

```text
과제 안내와 최종 결과물을 대조해 제출 준비를 확인해줘.

1. 필수 제출 파일과 현재 파일의 일치 여부
2. 처음 실행하는 사람이 따라 할 실행 순서
3. 정상 입력부터 결과까지의 실제 동작
4. 요구사항별 구현·검증 근거
5. 외부 코드의 출처·버전·적용 부분
6. 사용한 가정, 알려진 한계, 미완료 기능

실행과 검증을 실제로 수행한 범위에서 정리해줘.
완료하지 않은 기능이나 확인하지 않은 성과를 완료했다고 쓰지 마.
최종 산출물의 위치와 실행 방법이 분명하게 드러나도록 사용 안내를 정리해줘.
필수 요구를 충족하지 못한 부분이 있으면 영향과 우선 조치를 설명해줘.
제출·업로드·외부 전송은 하지 말고, 내가 검토할 수 있게 준비해줘.
```

담당자에게 전달하는 짧은 틀:

```text
[업무 목적]을 위해 [현재 완성한 기능]을 구현했습니다.
[대표 사례]에서 [실제 확인 결과]를 확인했습니다.
사용 순서는 [실행·입력·결과 확인]입니다.
[한계 또는 미완료 사항]은 남아 있으며 [영향]이 있습니다.
[필요한 추가 확인 또는 조정]을 제안합니다.
```

본인이 직접 확인할 것:

- 최종 파일을 저장했는가?
- 제출할 버전에서 실제 실행했는가?
- 완료한 일과 못 한 일을 구분해 설명할 수 있는가?
- 핵심 선택 두세 가지와 실제 검증 사례 하나를 자기 말로 설명할 수 있는가?
