# 04. 구현하고 실행하기

대상: 작업용 AI. 대괄호를 현재 과제에 맞게 바꿉니다.

```text
확인한 요구사항과 현재 코드를 기준으로 [이번에 만들 기능]을 구현해줘.

입력: [파일·사용자 선택]
결과: [화면·다운로드·파일]
필수 조건: [확인된 조건과 근거]
실행 환경: [현재 제공 환경과 실행 방식]
완료 기준: [어떤 입력에서 무엇이 보여야 하는지]

현재 프로젝트 구조와 실행 방법을 확인한 뒤 필요한 부분을 작성해줘.
입력 데이터를 바꾸면 결과도 다시 계산되게 하고, 예시 결과를 고정해 표시하지 마.
원자료를 임의로 수정하거나 업무 조건을 추측해 확정하지 마.
허용된 작업 공간과 도구 범위 안에서 구현해줘.

구현 후 해당 기능을 실제로 실행해서 확인해줘.
실행이 불가능하면 이유와 필요한 조치를 적고, 완료했다고 단정하지 마.

마지막에 다음을 짧게 알려줘.
1. 변경한 파일과 역할
2. 입력이 결과까지 처리되는 순서
3. 실제로 확인한 입력·예상 결과·관측 결과
4. 내가 화면에서 직접 확인할 순서
5. 남은 필수 기능과 한계
```

AI의 설명을 받고 직접 한 번 실행하세요. 실행 화면에 결과가 보인다는 사실과 계산이 맞다는 사실은 각각 확인해야 합니다.

작동하는 첫 기능을 만든 뒤:

```text
현재 작동하는 기능을 유지하면서 [다음 필수 기능]을 추가해줘.
변경 후 새 기능과 기존 기능을 함께 확인해줘.
이번 변경이 데이터 처리와 결과에 미치는 영향을 설명해줘.
```
