# 학습 자료를 사용하는 범위

이 저장소는 직접 만든 범용 사전 학습 자료입니다. 공식 시험 문제·첨부 자료·실제 작업물·공식 채점표를 수록하지 않습니다.

공개 GitHub 저장소 Clone이 허용된 시험이라도, 개인이 미리 준비한 프롬프트·학습 자료의 시험 중 반입까지 허용한다는 뜻인지는 별도 확인이 필요합니다. 운영 측에서 이 유형의 준비 자료 사용을 허용한 경우에만 시험에서 가져오세요. 준비 자료 때문에 현재 과제 지시나 제공 환경의 제한을 바꾸지 않습니다.

## 운영 측에 확인할 질문

“일반 공개 GitHub 자료의 Clone 허용 범위에, 개인이 사전에 공개해 둔 범용 작업 프롬프트·빈 기록 양식·설명서도 포함되나요? 실제 문제·파일·완성 답안은 포함하지 않은 자료입니다.”

이는 문의 예시이며 이 저장소가 대신 문의하거나 허가를 받았다는 뜻은 아닙니다.

## 실제 응시와 사전 연습

- 응시 중에는 제공된 AI·모델·도구·네트워크 범위를 따릅니다.
- 공개 코드 활용 시에도 라이선스와 과제의 허용 범위를 확인합니다.
- 문제·개인정보·첨부 파일·작업물·로그를 외부 GitHub에 보내지 않습니다.
- Git Push·외부 브라우저·개인 파일 업로드가 제한된 경우 그대로 준수합니다.
- 후속 서술형에서는 해당 안내에 따라 AI·외부 자료를 사용하지 않고 직접 답합니다. 연습용 면접 프롬프트는 사전 연습에서만 사용합니다.
- 제한된 접근이나 전송을 다른 경로로 우회하지 않습니다. 장애는 제공 도움말이나 신고 절차를 사용합니다.

이 문서는 특정 대회의 최신 운영 규정을 보장하지 않습니다. 새 안내·정정 공지·실제 응시 화면의 필수 조건을 확인하세요.
